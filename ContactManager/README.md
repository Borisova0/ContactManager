
# Менеджер контактов

## Описание проекта
Менеджер контактов — веб-приложение для хранения
и управления контактной информацией.

## Цель
Создать удобное приложение для управления
личными контактами.

## Основные функции
- Добавление контактов
- Редактирование контактов
- Удаление контактов
- Поиск по имени и телефону
- Фильтрация по группам
- Сохранение данных в браузере
- Проверка введённых данных

## Используемые технологии
- HTML
- CSS
- JavaScript
- LocalStorage

## Структура проекта
- index.html — структура сайта
- style.css — оформление
- script.js — функциональность
- README.md — описание проекта

## Запуск
1. Скачать папку проекта.
2. Открыть файл index.html в браузере.
3. Добавить контакт через форму.

## Тестирование
Подготовлено 8 тестовых сценариев:
- 4 проверки основных функций
- 2 проверки ошибочного ввода
- 2 проверки граничных значений

## Ограничения
- Нет синхронизации между устройствами.
- Нет авторизации.
- Данные хранятся в текущем браузере.



## Анализ аналогов и источники

При разработке были рассмотрены три приложения
для управления контактами.

1. Google Контакты — хранение, поиск и
   группировка контактов.
   https://contacts.google.com/

2. Apple Контакты — хранение и редактирование
   контактов на устройствах Apple.
   https://support.apple.com/ru-ru/guide/iphone/

3. Microsoft Outlook — управление контактами.
   https://support.microsoft.com/ru-ru/outlook

4. MDN Web Docs — документация по HTML,
   CSS и JavaScript.
   https://developer.mozilla.org/ru/
