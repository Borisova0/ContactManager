
# Менеджер контактов

## Описание проекта
Менеджер контактов — веб-приложение для хранения
и управления контактной информацией.

## Цель
Создать удобное приложение для управления
личными контактами.

## Основные функции
- Добавление контактов
- Редактирование контактов
- Удаление контактов
- Поиск по имени и телефону
- Фильтрация по группам
- Сохранение данных в браузере
- Проверка введённых данных

## Используемые технологии
- HTML
- CSS
- JavaScript
- LocalStorage

## Структура проекта
- index.html — структура сайта
- style.css — оформление
- script.js — функциональность
- README.md — описание проекта

## Запуск
1. Скачать папку проекта.
2. Открыть файл index.html в браузере.
3. Добавить контакт через форму.

## Тестирование
Подготовлено 8 тестовых сценариев:
- 4 проверки основных функций
- 2 проверки ошибочного ввода
- 2 проверки граничных значений

## Ограничения
- Нет синхронизации между устройствами.
- Нет авторизации.
- Данные хранятся в текущем браузере.
